# Rivals Chess

A 3D chess game for kids: heroes vs villains. Every capture ends with the attacker's ultimate.

**Play:** https://arisouss.github.io/rivals-chess/

- One file (`index.html`), no install. Works in Chrome, Edge and Safari, on computer, tablet and phone.
- 1 Player against the computer (Easy, Medium, Hard) or 2 Players on one device.
- Move by tap, drag, voice ("knight to f3") or typing.

Private family fan project. Characters belong to Marvel; not for sale or distribution.

## How updates go live
Every push to `main` is published automatically by GitHub Pages (about 1 to 2 minutes).
